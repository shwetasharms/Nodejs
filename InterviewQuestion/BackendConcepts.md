Access Token vs Refresh Token during Authentication!

Let’s say you go to watch a movie at a theatre.

🗣️Access Token is like your movie ticket.
* It allows you to enter the theatre and watch the movie.
* But it only works for a short time (for that one show).
* After that, it expires and you need a new ticket.

🗣️Refresh Token is like a membership card.
* If your movie ticket expires, you don’t need to log in again.
* You just show your membership card and get a new ticket easily.
* The membership card is valid for a longer time.

What this means in apps:
*Access Token is used to access the app.
 It expires quickly (in minutes).
*Refresh Token is used to get a new access token
 without asking the user to log in again.
 It lasts longer (days or weeks).

In short:
* Access Token = Short-term pass
* Refresh Token = Long-term pass to get a new one

Both are used together to keep you logged in safely and smoothly.
